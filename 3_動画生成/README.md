# 3_動画生成

## 役割
台本をもとに、実際のTikTok動画ファイル（縦型・9:16）を生成する工程。
講座メソッドの「AI音声」もここで担当（台本を音声化する）。

## ★ 実行方法（自動・1コマンド）
台本テキストを1つ渡せば、音声生成から合成まで通しで走り、完成動画が出る。

```bash
cd 3_動画生成/scripts
./.venv/bin/python make_video.py ../音声/本番_013.txt
```
→ `output/本番_013_TikTok.mp4`（BGMなし）と `output/本番_013_YouTube.mp4`（BGMあり）ができる。

前提: **VOICEVOX.app を起動**／**外付けSSD「Extreme SSD」を接続**。
オプションや仕組みの詳細は [scripts/README.md](scripts/README.md)。

以下は、この自動化が何をやっているか（＝Premiere Proでの手作業の内容）の説明。

## 完成形の見本
- 目指す仕上がりは [完成形の仕様.md](完成形の仕様.md) を参照（縦書き白ボックス＋黒極太テロップ／散歩背景／LINE誘導など）。

## ベーステンプレート
- チャンネルの動画フォーマットは [テンプレート/ベースプロマネ.prproj](テンプレート/) が基準（縦型1080x1920）。
- テロップスタイル・LINE誘導・いいね保存オーバーレイ・SE・BGM・お金(金額)部品が含まれる。詳細は [テンプレート/README.md](テンプレート/README.md)。
- 新規動画はこれを複製 → 背景・音声・テロップを差し替えて作る（現状は手動〜半自動）。

## 入力（前工程 2_台本生成 から受け取るもの）
- 台本ファイル（フック・本編・CTAのナレーション原稿＋テロップ文言＋シーン指示）
- キャプション/ハッシュタグ案

## 手順
### ① AI音声（ナレーション生成）
- 使用ツール: **Web版VOICEVOX（su-shiki） https://www.voicevox.su-shiki.com/split**
- まず台本テキストを **[プロンプト_AI音声用整形.md](プロンプト_AI音声用整形.md)** でAI音声用に整形する。
  - 1行30文字以内で改行（助詞・文節・句読点の切れ目で区切る）／句読点「、」「。」は出力しない。
  - ※ 上記VOICEVOXは長文を分割して読ませるため、この30字改行の整形が必要。
- 整形済みテキストを上記VOICEVOXに入れてナレーション音声を生成する。
- 音声設定:
  - 話者（キャラ）: **青山龍星**
  - 再生速度: **1.2倍速**

### ② 映像素材（背景）の準備
- 背景は **散歩（ウォーキング）動画** を使う。
- [assets/背景動画/](assets/背景動画/) に散歩動画をアップロードしておき、それを背景として敷く。
- （参考動画の映像はそのまま流用せず、この背景動画＋テロップで構成する）

### ③ 動画編集・合成
- チャンネルの既存動画と**同じ形式**で作る。
  - 背景: 散歩動画（[assets/背景動画/](assets/背景動画/)）
  - テロップ: **縦文字（縦書き）** で、既存動画と同じ見せ方に揃える
  - ナレーション: ①のVOICEVOX音声（青山龍星・1.2倍速）
  - SE（効果音）: [assets/SE/](assets/SE/) の効果音を、テロップ切り替わり・強調ポイントに合わせて入れる
- 背景動画＋ナレーション音声＋縦文字テロップ＋SE を合成する。
- 縦型 1080x1920 / 9:16 で書き出す。
- 編集ツール: 現状はPremiere Proで作業。最終的には全工程を自動化する想定のため**ツールは不問**（自動化しやすい手段でよい）。

### ④ 出力（2種類書き出す）
同じ内容で、投稿先別に2バージョンを書き出す。BGMの有無だけが違う。

| バージョン | BGM | 備考 |
|---|---|---|
| **YouTube用** | あり（[assets/BGM/](assets/BGM/) を埋め込む） | BGMまで入れて完成 |
| **TikTok用** | なし | BGMはTikTokアプリ内で付けるため動画には入れない |

- 背景・ナレーション・縦文字テロップ・SEは両バージョン共通。BGMの有無のみ変える。

## 出力（次工程 4_投稿 へ渡すもの）
- 完成した動画ファイル（.mp4）× 2種類（YouTube用＝BGMあり／TikTok用＝BGMなし）
- 投稿用キャプション/ハッシュタグ（台本から引き継ぎ）

## 出力先の例
- `output/動画_YYYYMMDD_001_YouTube.mp4`（BGMあり）
- `output/動画_YYYYMMDD_001_TikTok.mp4`（BGMなし）
