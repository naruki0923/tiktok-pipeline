# 完成形の仕様（チャンネルの型）

編集後の完成形の見本。新規動画はこの見た目に揃える。

## 参考動画（完成見本）
- 運用しているTikTokチャンネルの投稿
- 例: https://www.tiktok.com/@<アカウント>/video/<動画ID>
- キャプション例: 「知らないとやばい！ 退職後に国保に加入すると高額請求で驚きます #退職 #会社辞めたい #給付金」
- 数値例: いいね11.4K / コメント71 / 保存9592 / シェア2277（保存が非常に多い＝有益系の勝ちパターン）
- **実物サンプル**: [完成形サンプル/完成動画_国保サンプル.mp4](完成形サンプル/完成動画_国保サンプル.mp4)

## 画面構成
- **解像度**: 縦型 9:16（サンプルDL版は720x1280、投稿元は1080x1920想定）
- **尺**: 約1分半（サンプルは約1:36）
- **背景**: 散歩動画（実際の街歩き映像。assets/背景動画/ の4K散歩動画を使用）

## テロップ（最重要・チャンネルの identity）
- **縦書き**（上→下、列は右→左）
- **白い角丸ボックス**の上に、**極太ゴシック体**（heavy / bold）
- 色使い:
  - **通常は黒**文字
  - **フック・強調ワードは赤**（例: 冒頭の「知らないとヤバい」が赤、続く説明は黒）
- **大きめ**サイズ（画面の高さの大部分を占める。1〜複数列）
- 位置: 画面中央〜やや右寄り
- ナレーション（VOICEVOX 青山龍星・1.2倍速）と同じ内容を、話に合わせて切り替え表示

## 構成の流れ（サンプルより）
1. **フック**（冒頭）: 赤文字の煽りワード＋要点（例:「知らないとヤバい／退職後に国保に加入すると高額請求で驚きます」）
2. **本編**: 制度の解説。金額の具体例を出す（例:「例えば年収800万だった人が…」）
3. **CTA（終盤）**: LINE誘導 →「**無料の個別面談に参加してみてください**」→ プロフィールのLINEリンクへ

## 演出要素
- **指差し（タップ手）アイコン**（426429.png）＋フォロー誘導
- **いいね・コメント・保存**の促進オーバーレイ（いいね・コメント・保存画像.mp4）
- **金額・お金系の表示**では SE「レジスターで精算」＋「金額表示」を入れる
- 終盤に **LINE誘導**（プロフィール画面スクショ IMG_4766.jpg ＋「プロフィールのリンクを押す」案内）

## 投稿バリエーション
- TikTok用: BGMなし（TikTok内でBGM付与）
- YouTube用: BGMあり（動画に埋め込み）
