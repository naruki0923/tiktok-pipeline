# AI音声用テキスト整形プロンプト（AI音声生成の前処理で使用）

2_台本生成 で校正済みの台本テキストを、AI音声に入れやすい形に整形するプロンプト。
1行30文字以内で改行し、句読点（、。）は出力しない。

## 前段
- 入力は 2_台本生成 の校正済みテキスト（[../2_台本生成/プロンプト_文章整理.md](../2_台本生成/プロンプト_文章整理.md) の出力）

---

## プロンプト本文

```
これを1行あたり30文字以内のところで改行してください。
ただし改行位置は助詞や文節の切れ目、句点、読点になるように工夫して文章の視認性を優先してください。
必ず最後まで出力し切ってください。文章出力時に「、」「。」は出力しないでください。
```

---

## 使い方
1. 2_台本生成 の校正済みテキストを用意する
2. その本文の前に上のプロンプトを付けてAIに投げる
3. 30文字以内で改行され、句読点が除かれたテキストを得る
4. そのテキストを Web版VOICEVOX（su-shiki） https://www.voicevox.su-shiki.com/split に入れてナレーション音声を生成する
   - ※ このVOICEVOXは長文を分割して読ませるため、上記の30字改行整形が必要
