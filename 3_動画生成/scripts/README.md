# scripts

動画生成の自動化スクリプト置き場。

## パイプライン全体（台本 → 完成動画）
```
台本.txt
  │  ① voicevox_tts.py … VOICEVOXで音声生成＋各行タイミング(JSON)出力
  ▼
narration.wav + narration.timing.json
  │  ② compose_video.py … 背景＋音声＋縦書きテロップ を合成
  │      （内部で telop_render.py を呼び、行ごとに縦書きテロップPNGを生成）
  ▼
output/○○_TikTok.mp4（BGMなし） と ○○_YouTube.mp4（BGMあり）
```

**この①②をまとめて実行するのが make_video.py（通常はこれを使う）。**

- **make_video.py** … 台本を渡すだけで完成動画まで一発。①②を順に呼ぶラッパー。
- **telop_render.py** … 縦書きテロップPNG生成（白角丸ボックス＋黒極太ゴシック／フックは赤）。単体テスト可。
- **compose_video.py** … 背景動画＋音声＋テロップを合成し、TikTok用/YouTube用の2本を書き出す。

## make_video.py — 台本 → 完成動画（1コマンド）
```bash
cd 3_動画生成/scripts
./.venv/bin/python make_video.py ../音声/本番_013.txt
```
これだけで `../音声/本番_013.wav`（＋timing.json）と
`../output/本番_013_TikTok.mp4` / `本番_013_YouTube.mp4` ができる。

### 自動で決まるもの（指定しなくてよい）
- **出力名** … 台本のファイル名（`本番_013.txt` → `本番_013`）。`--name` で上書き可
- **背景動画** … `/Volumes/Extreme SSD/素材/動画・画像素材/4K 散歩動画/` から自動で選び、シャッフルして場面ごとに割り当てる。
  `--seed 7` で並び順を固定（毎回同じ背景になる）／`--bg <path>` で明示指定（複数可）
  - **使えない素材は自動で除外**する:
    - 60秒未満の素材（場面の尺に足りず背景が音声より短くなるため）。`--min-bg-secs` で変更可
    - **尺が完全一致する素材＝同じ映像の別名コピー**（実例: `絵以上.mp4` は `Yokohama Night walk [4K].mp4` と同一映像）。
      同じ街が1本の動画に2回出るのを防ぐ
  - 尺の判定（ffprobe）は 4GB級×11本で遅いので `.bg_probe_cache.json` にキャッシュしている（2回目以降は一瞬）
  - 素材フォルダには**夜の映像（Yokohama Night walk / 歌舞伎町 Night Walk）も含めてOK**という方針。ランダムでこれらも普通に採用される。
    特定の背景で作り直したいときは、実行時に表示される「使う順」を見て `--seed` を変える（音声は再利用されるので速い）か、`--bg` で明示指定する
- **BGM** … `../assets/BGM/` の mp3 を自動採用
- **音声の作り直し** … 台本より新しい wav+timing が既にあればTTSはスキップ（合成のやり直しが速い）。
  作り直したいときは `--force-tts`

### 主なオプション
| オプション | 意味 |
|---|---|
| `--name 本番_014` | 出力ベース名（既定: 台本のファイル名） |
| `--seed 7` | 背景の並び順を固定（同じ値なら毎回同じ背景） |
| `--bg <path>` | 背景を明示指定（複数可。指定すると自動選定しない） |
| `--force-tts` | 音声を作り直す |
| `--tts-speed 1.2` | ナレーションの話速 |
| `--speaker 青山龍星` / `--style ノーマル` | 話者・スタイル |
| `--host <url>` | VOICEVOX ENGINE の URL（既定 `http://127.0.0.1:50021`） |
| `--min-bg-secs 60` | 背景素材の最短の尺 |

### compose_video.py のオプションはそのまま書ける
未知のオプションは compose_video.py に**そのまま透過で渡される**ので、下記のように混ぜて書ける。
```bash
./.venv/bin/python make_video.py ../音声/本番_013.txt \
  --red-lines 3 --title-lines 3 --scene-secs 12 --tiktok-only --seed 7
```
⚠️ **`--speed` だけは衝突する**ので使い分ける:
- `--speed` … **背景**の再生速度（compose_video.py。既定1.2）
- `--tts-speed` … **ナレーション**の話速（voicevox_tts.py。既定1.2）

### 台本の書き方（そのまま渡せる形）
[../プロンプト_AI音声用整形.md](../プロンプト_AI音声用整形.md) の形式。実例は [../音声/本番_013.txt](../音声/本番_013.txt)。
- 1行1フレーズ（30字以内）・**句読点なし**
- **文末は空行**（空行で文を区切る。SEの位置判定にも使う）
- 「**いいねと保存**」の一文を入れる → いいね・保存オーバーレイが自動で入る
- 最後に「**無料の個別面談に参加してみてください**」等のCTA → LINE誘導オーバーレイが自動で入る

### 前提
- **VOICEVOX.app を起動しておく**（①でAPIを叩くため）
- **外付けSSD「Extreme SSD」を接続しておく**（背景動画の実体。未接続ならエラーで止まる）
- Pillow を使うため、必ず `.venv/bin/python` で実行する

### うまくいかないとき
どの段階で落ちても、理由を1行で出して**終了コード1**で止まる（cron等での自動実行を想定）。
| 出るメッセージ | 対処 |
|---|---|
| `VOICEVOX ENGINE に接続できません` | VOICEVOX.app を起動する |
| `背景動画フォルダが見つかりません` | 外付けSSDを接続する |
| `台本が見つかりません` | パスを確認する |

### 実測
サンプル台本（9行・16.4秒）で、音声生成＋2本書き出しまで**約31秒**（M系Mac / 4K背景）。
音声を作り直さない場合（合成のみ）はもっと速い。

## compose_video.py — 合成だけを個別に回す
（通常は make_video.py 経由。単体で叩くのはデバッグ・差し替え時）

### compose_video.py の使い方
```bash
cd 3_動画生成/scripts
./.venv/bin/python compose_video.py \
  --audio ../音声/narration_001.wav \
  --timing ../音声/narration_001.timing.json \
  --bg "…/4K 散歩動画/【4K】平日の新宿をのんびり散歩【Tokyo Walk】.mp4" \
  --bg "…/4K 散歩動画/【4K Tokyo walk】原宿 Harajuku #94 東京 散歩.mp4" \
  --out-dir ../output --name 動画_001 \
  --bgm "../assets/BGM/ssstik.io_1729783119638 (online-audio-converter.com).mp3" \
  --scene-secs 15 --speed 1.2 --red-lines 1
```
- `--bg` … 背景動画。複数指定可（場面ごとに順番に使う）
- `--scene-secs N` … 背景1場面のおおよその長さ（秒）。この間隔でテロップ境界に合わせて場面転換（既定15）。短い動画は転換なし
- `--speed` … 背景の再生速度（既定1.2倍）
- `--seg-starts "60,300,600"` … 各場面の開始秒を指定（前進している部分を選ぶ用）
- `--red-lines N` … 先頭N行を赤テロップ（フック）にする
- `--tiktok-only` … TikTok用のみ書き出す
- Pillow を使うため、必ず `.venv/bin/python` で実行する

### 仕様上のポイント
- **テロップは常に表示**（空白の瞬間を作らない）。各テロップは次のテロップ開始まで表示し続ける。
- **背景の場面転換はテロップの切り替わりと同一フレーム**（フレーム単位で一致。整数フレームで制御）。
- **改行は助詞・文節の切れ目**（fugashi 形態素解析）。数字・英字の途中では割らない。
- 句読点の間（音声）は約0.2秒（参考動画実測。voicevox_tts.py の `--gap 0.2`）。

### SE（効果音）の自動挿入
- **文末（。＝台本の空行）ごとに必ず** SE（既定: シャン）。voicevox_tts.py が空行位置を `sentence_ends` として timing.json に記録する。
- **金額テロップ**（円/万/年収/給付 等を含む）に レジスター＋金額 のSE。
- 引数: `--sentence-se`（文末SE）/ `--money-se`（金額SE・カンマ区切り）/ `--no-se`（無効）/ `--se-dir`。
- ※ 台本の各文末に空行を入れておくこと（句読点を消しているため空行で文末を判定）。

### オーバーレイ（自動合成）
素材（`テンプレート/いいね・保存.mp4` / `テンプレート/LINE誘導.mp4`）は**アニメーション・効果音・サイズ・位置まで
完成済み**のグリーンバック動画。緑を抜いてそのまま 0:0 に重ね、**素材の音声もミックス**する。

- **クロマキー**: グリーンバック **#73D44C**。
  - ⚠️ similarity は **0.25未満**（既定0.10）にすること。chromakeyは色差のみで判定するため、
    大きくすると白黒（無彩色）のアイコンまで透過して消えてしまう。
- **いいね・保存**: 台本で「**いいね/保存**」を含む文の**先頭フレーム**から再生（テロップと1フレームもズレない）。
  - 台本にこの一文を入れておく（例:「あなたのおすすめには表示されませんので／忘れないようにいいねと保存してください」）。
- **LINE誘導**: 台本の**CTA文**（「個別面談/説明会/プロフィール/リンク」を含む文。無ければ最後の文）の
  **先頭フレーム**から再生。素材が終わるまで動画を自動延長する。
  - 台本の最後に「**無料の個別面談に参加してみてください**」を入れておく。
- **SEは鳴らさない**: この2つの文では素材が自前の効果音を持つため、SEを自動的にスキップする。
- `--ov-volume`（既定0.3）で素材の音量調整。`--no-overlay` で無効。
- `--no-overlay` で一切入れない。

## voicevox_tts.py — ナレーション音声の自動生成
台本テキストを VOICEVOX に投げて、青山龍星・1.2倍速のナレーション音声（wav/mp3）を自動生成する。

### 事前準備（初回だけ）
1. **VOICEVOX（無料）をインストール**
   - 公式: https://voicevox.hiroshiba.jp/
   - Mac版をダウンロードして `/Applications` に入れる。
2. **VOICEVOX.app を起動**しておく（起動中は自動で `http://127.0.0.1:50021` にAPIが立つ）。
   - ※ アプリを開いている間だけAPIが有効。閉じると使えない。
3. 必要ツール: python3 / ffmpeg（導入済み）。

### 使い方
```bash
cd 3_動画生成/scripts

# 基本（青山龍星・1.2倍速・mp3も出力）
python3 voicevox_tts.py ../音声/サンプル台本.txt -o ../音声/narration_001

# 話者・速度を変える
python3 voicevox_tts.py 台本.txt -o out --speaker "青山龍星" --style "ノーマル" --speed 1.2
```

### 入力テキストの形式
- **1行1フレーズ**（[../プロンプト_AI音声用整形.md](../プロンプト_AI音声用整形.md) で 30字改行・句読点なし にしたもの）
- **空行 = 少し長めの間（ま）** として無音が入る（段落の区切りに使う）

### 出力
- `<out>.wav` と `<out>.mp3`（`--no-mp3` でmp3を省略可）
- 行間に短い無音（`--gap` 秒）、空行に長め無音（`--blank-gap` 秒）を自動挿入

### よくあるエラー
- `VOICEVOX ENGINE に接続できません` → VOICEVOX.app が起動していない。起動してから再実行。
- `話者 '青山龍星' が見つかりません` → 利用可能な話者一覧が表示されるので、正しい名前を `--speaker` に指定。

### 補足
- 現状は su-shiki の Web版VOICEVOX を手動で使っているが、自動化ではこのローカル版APIを使う。
  話者（青山龍星）・速度（1.2倍）は同じに揃えている。
