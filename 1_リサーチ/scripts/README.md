# 1_リサーチ scripts

参考動画の候補集めを自動化したもの。これまで対話（Claude＋ブラウザ操作）でやっていた
「検索 → 数値を見る → 黄金式で絞る」をスクリプトにした。

```bash
# playwright が要るので 4_投稿 の venv で動かす
cd 1_リサーチ/scripts
../../4_投稿/scripts/.venv/bin/python auto_research.py -o ../候補_20260803.json
```

## auto_research.py がやること

| 手順 | 中身 |
|---|---|
| ① 検索 | `/search/video?q=<語>` のグリッドから動画URLを集める（未ログインでも見える。**1語12件が上限**なので6語振る） |
| ② 除外 | `採用履歴.tsv` にある動画を30日間スキップ（再利用禁止ルール） |
| ③ 実数取得 | **yt-dlp** で 再生数・尺・投稿日・いいね・コメント・投稿者。失敗は**レート制限**が多いので3回リトライ |
| ④ フォロワー | `/search/user?q=<アカウント>` から取る（プロフィールページは「Please wait」で読めない） |
| ⑤ 採点 | **黄金式（フォロワー×100＜再生）**を軸に Eng率 で並べ、上位を候補JSONに書く |

足切り: 再生2万以上 / 実尺45〜180秒 / DL可能。すべて `auto_research.py` 冒頭の定数。

## 出力

```json
{ "generated_at": "...", "keywords": [...], "covered_angles": [...],
  "candidates": [ {"url": "...", "author": "...", "title": "...", "views": 73500,
                   "duration": 77.0, "followers": 9236, "golden_ratio": 7.96, ...} ] }
```

これを `統括/Discordbot/pipeline.py` が上から順に試す（文字起こし→季節性判定→台本）。

## 注意

- **季節性の判定はここではやらない。** 指標だけで選ぶと「1〜5月に退職すると…」のような
  月依存ネタを拾ってしまう（本番_029の差し戻し）。判定は文字起こし後に
  `2_台本生成/scripts/write_script.py` がLLMで行い、NGなら次の候補へ回す。
- **TikTok側の作りは頻繁に変わる。** 取れなければ静かに諦めて次へ進む作りにしてあり、
  全滅すると終了コード2で「候補ゼロ」を返す（呼び出し側がフォールバックできる）。
  詰まったときの既知の回避策は memory `research-tiktok-scrape-method` に蓄積している。
- Chromeは `4_投稿/scripts/browser_ctx.py`（自動化フラグなし起動＋CDP後接続）を借りている。
  TikTokの検知回避のためで、Playwrightに起動させてはいけない。
- **ただしプロファイルは投稿用と完全に分けている。**
  リサーチ = `1_リサーチ/scripts/.chrome-research` / ポート **9223** / **未ログイン**
  投稿     = `4_投稿/scripts/.chrome-profile` / ポート 9222 / 投稿用アカウントでログイン済み
  業務アカウントでログインしたままスクレイピングすると、垢に何かあった時に投稿手段ごと
  巻き込むため（2026-08-03 社長判断）。検索・フォロワー取得は未ログインで読めるので不都合はない。
  副次効果として、ログイン時に検索ページのサイドバーへ紛れ込む**自分の動画の混入も無くなる**。
- 応答しなくなったChromeは `browser_ctx.connect_healthy()` が自動で落として起動し直す
  （無人実行で人が直せないため）。
