# 1_リサーチ（参考動画の選定）

## 役割
「伸びている参考動画」を見つけて選定する工程。ここで選んだ動画が、後工程（ダウンロード → 文字起こし → リライト → AI音声）の素材になる。

## メソッド全体像（講座準拠）
参考動画の選定（★最重要）→ ダウンロード → AI文字起こし → AI文章整理（リライト）→ AI音声
※このディレクトリは「参考動画の選定」を担当。以降は 2_台本生成・3_動画生成 へ。

## 参考動画の選定基準（3つ）
選ぶ動画は、以下の3条件を満たすものにする。

1. **直近3ヶ月以内**
   - 投稿日が直近3ヶ月以内の動画に絞る（今のトレンド・伸びている型を反映するため）。
2. **退職の内容が入っているか**
   - 退職・退職給付金・失業保険・退職代行など「退職」に関するテーマが含まれているか確認する。
3. **アフィリエイトURLに繋げられるか（最重要）**
   - その動画の内容から、自分のアフィリエイト導線（LINE公式アカウント＝無料説明会への登録）へ自然に繋げられるかどうか。
   - 繋げられない内容（退職と無関係、給付金の導線に落とせない）は選ばない。

## 「伸びているか」の判断（外から見える代理指標）
参考動画（他人の動画）は、平均再生率などの本人アナリティクス（非公開）は見えない。
そのため、公開されている数値で「伸びているか」を代理判断する。

- **黄金式（★最重要）: `フォロワー数 × 100 ＜ 再生数`**
  - 通常「フォロワーの10〜20倍再生されれば良い動画」と言われるが、参考動画に選ぶのは **100倍** を超えるもの。
  - 例: フォロワー100人で1万再生／フォロワー1000人で10万再生 → これを満たす動画を探す。
  - 狙いは「アカウントパワー（演者の知名度・ファン力）ではなく、コンテンツパワー（企画・構成・有益性）だけで初見を掴んで伸びた動画」を見つけること。
  - 有名アカウントの100万再生は「有名だから伸びた」可能性が高く、無名の自分が真似ても再現しない。フォロワー少 × 高再生こそがリサーチ教材。
- **エンゲージメント率**: いいね数・保存数・コメント数 ÷ 再生数 が高いものを優先
- **保存数**が多い動画は「後で見返したい＝有益」と判断されやすく、参考価値が高い
- （任意）気になるチャンネルは今の登録者数を記録しておき、後日また見て伸びを追跡する
- ※ 平均再生率・登録者の実増加は自分の投稿動画で測る指標 → 5_分析 が担当

## 選定の進め方（TikTok内リサーチ手順）
1. TikTokの検索窓に退職・退職給付金系のキーワードを入力（例: 退職給付金／失業保険／退職代行／退職 給付金 もらえる 等）。
2. 検索結果で **「動画」タブ** → 右上の3本線 → **フィルター**。
3. フィルターを **並び替え=いいね順／投稿日=今月** に設定する。
   - いいね順: TikTokに再生数順が無いため、いいね数を再生数の代理指標として使う。
   - 今月: トレンドの鮮度が命（半年前のバズは無意味）。※本プロジェクトの選定基準は「直近3ヶ月」なので、今月で足りなければ範囲を広げて可。
4. 上から順に見て、**黄金式（フォロワー×100＜再生数）** を満たす動画をプロフィールで確認しながら拾う。
5. 選定基準3条件（直近3ヶ月／退職テーマ／LINE導線に落とせる）＋代理指標でフィルタし、候補をリスト化する。
6. 候補ごとに「動画URL・投稿日・テーマ・再生数/いいね/保存・**当たっている要因（コメント欄から拾う）**・LINE導線への繋げ方メモ」を記録する。
   - 当たった理由は自分の推測ではなく **コメント欄の視聴者の本音（悩み・願望・ニーズ）** から逆算する。次の企画の種になる。

> 詳しい背景・考え方は [リサーチ手法_TikTok_アルファギルド.md](リサーチ手法_TikTok_アルファギルド.md) を参照。

## ルール: 採用は「その時点で一番いいもの」を1本
- 候補が複数出たら、**その時点で最良の1本**を採用する（下の「採用基準」＋Eng率/保存率で判断）。
- ただし直近30日以内に採用済みの動画は除外した上での「一番いいもの」を選ぶ（下記の再利用ルール）。

## ルール: 同じ参考動画は30日間は再利用しない
- 一度「採用」した参考動画は、**採用日から30日間（＝1ヶ月）は再び採用しない**。
- 採用した動画は `採用履歴.tsv`（採用日・動画URL・出力・メモ）に自動記録され、次の採用時に自動チェックされる。
  30日以内に同じ動画を採用しようとすると中断される。
- 判定は動画ID（URL末尾の `/video/<数字>`）で行うので、短縮URL/クエリ付きでも同一動画として弾かれる。

## 採用したら次工程へそのまま流す（1発）
参考動画を1本決めたら、URLを渡すだけで「30日チェック → 連番採番 → 文字起こし → 履歴記録」まで一気に進む。
```bash
cd 2_台本生成/scripts
./.venv/bin/python use_ref.py "https://www.tiktok.com/@user/video/1234567890"
# → 2_台本生成/文字起こし/ref_NNN.txt を生成し、次の一手（AI台本化→format_script.py）を表示
```
- 30日ルールに引っかかると中断（どうしても使うときだけ `--force`）。
- 出力名を固定したいときは `-n 名前`（`ref_名前.txt`）。メモは `--memo "..."`。

## 出力（次工程 2_台本生成 へ渡すもの）
- 選定した参考動画リスト（動画URL・投稿日・テーマ・アフィリエイト導線への繋げ方）
- 採用した動画は `use_ref.py` 経由で `2_台本生成/文字起こし/ref_NNN.txt` として直接渡る

## 出力先の例
- `参考動画リスト.md`（候補・採用の一覧）／ `採用履歴.tsv`（採用済みと日付。30日再利用禁止の判定に使う）
