# 台本作成ルール

参考動画の文字起こしをもとに台本を作るときの決まりごと。
このルールで作った文章を `scripts/format_script.py` に通すと、`make_video.py` 用の台本テキストになる。

## フロー上の位置
```
1_リサーチ(参考動画を選定)
  → 参考動画を文字起こし
  → 【このルールで台本化】← ここ
  → scripts/format_script.py で整形
  → 3_動画生成/make_video.py で動画化
```

## 基本方針
- **完コピ推奨**（構成・企画・切り口はそのまま。目安 約90%パクり・10%だけ独自）。
  似た構成の動画がTikTokに多数あるので、伸びている参考動画はそのまま台本化してよい。
- **参考動画のURLは台本シートの G1 に貼る**（過去シートの運用を踏襲）。
- **★尺の目安: 450〜500字 ＝ 65〜72秒。上限520字（75秒）。**【2026-07-30 実測で改訂】
  - 完成動画14本の実測値は **6.9字/秒**（6.6〜7.3のレンジ／VOICEVOX青山龍星・1.2倍速・空白除く）。
    旧ルールの「498字＝1分（8.3字/秒）」は**20%速すぎる見積り**で、これを信じて書くと必ず尺が伸びる。
    実際、本番_017〜030の平均は583字＝**84秒**まで膨らんでいた。
  - **なぜ尺を切るのか**: 尺×視聴維持率の相関は **r=-0.48**（長いほど確実に維持率が落ちる）。
    そして **フォロワー転換率×維持率は r=+0.44**。＝**尺を切る→維持率が戻る→フォロワーが増える**。
    旧体制（平均77秒）は維持率28.8%・転換率0.45%帯、新体制（平均85秒）は22.3%・0.24%帯。
  - **字数を削る方法は「項目を減らす」**。1項目あたりの説明を薄めると価値が落ちて逆効果。
    6つ→3つ、5つ→3つに減らして1つ1つを厚くする（旧体制の勝ちパターンは3〜4項目）。
- **1行は短く**：実物は5〜20字、最大でも30字（`format_script.py --max-len 30` に対応）。

## 構成（4パート・上から順に）

### ① タイトル（フック）— 冒頭
列挙型（「〜3選」など）が基本。**参考動画のタイトルをベースに完コピ**してよい。
最後に「特に最後の3つ目は／知っておかないと（大損する）内容です」と入れて**保存を促す**。

> ⚠️ **重要（誤発火防止）**: フック・イントロなど②のいいね誘導行より前に、
> 「**いいね**」「**保存**」という語を入れてはいけない。
> 動画生成のオーバーレイは「いいね/保存」を含む**最初の行**で発火するため（compose_video.py）、
> 前に出すと②の正しい位置ではなくそこで誤発火する。
> 参考動画が「保存必須です」等と言っていても、フックでは「必ず最後まで見てください」
> 「知らないと大損する内容です」等、**その2語を使わない言い換え**にすること。
> （②の固定文言と、動画生成コマンドの `--title-lines <フック行数>` も忘れず。）

実例（【60歳の給付金】）:
```
ほぼ10割が知らない
60歳になった時点で申請すれば
受け取れる給付金3選
特に最後の3つ目は
知っておかないと大損する内容です
```

#### ★冒頭2秒（1行目）の作り方 — 最優先ルール【2026-07-21 実測フィードバック】

**なぜ**: 5_分析で全投稿の視聴維持を実測したところ、**例外なく「0:02」で最大の離脱**が起きていた
（1.1M再生のバズ動画も同様）。1行目＝再生開始〜2秒に流れる音声が、視聴継続を決める唯一最大のレバー。
実際、最高実績の台本_017（維持率36.4%・再生4,317）は1行目が「**知らないと大損する、〜**」と即・損失を突く型。
逆に低実績の018/020/021は3本とも「**実は〜**」という前置きで始まり、維持18〜25%に留まった。

**1行目の鉄則（この順で優先）**
1. **「実は」「今回は」「みなさん」等の前置きで始めない。** 一撃目から本題。前置きは1秒を捨てるのと同じ。
2. **具体的な数字か"損"を最初の一節に置く。** 「3倍」「50万円」「もらえなくなる」を後ろに回さない。
3. **視聴者を名指しする。** 「退職を考えているなら」「65歳が近い人は」で"自分ごと"にする。
4. **1行目は短く言い切る。** 「〜場合があります」等の保険は2行目以降へ逃がす（誇大回避は保つ）。
5. **完コピ対象でも1行目だけは磨く。** 本編は参考動画の完コピでよいが、フック1行目は上記に合わせて作り直す。

**実測ベースの Before → After（自分の投稿から）**

| 動画 | Before（弱い＝前置き型） | After（推奨＝即・損失/数字/名指し） |
|---|---|---|
| 018 | 実は退職前に受け取れる、給付金7選。 | 退職届を出す前に見て。退職後には二度と申請できない給付金が7つあります。 |
| 020 | 実は退職後の国民健康保険料は、申請するだけで大きく下げられる場合があります。 | 退職後の国保、そのまま入ると会社員時代の約3倍。でも申請1枚で下げられます。 |
| 021 | 実は退職するタイミングを1ヶ月ずらすだけで、受け取れるお金が大きく変わる場合があります。 | 65歳を過ぎて退職すると、失業手当はほぼ一時金だけ。1ヶ月早めれば数十万円変わります。 |

※ After も **事実ベースを維持**（「約3倍」「一時金だけ」等はいずれも本編で説明している事実）。断定・誇大（「必ず」「全員」）はしない。
※ フックに「いいね/保存」の2語を入れない制約は従来どおり（②で誤発火するため）。

#### ★どの型で書くか — 伸びる型【2026-09-04 実測フィードバック】

**なぜ**: 042〜066の23本の実数を取ったところ、上位2本（051＝257,200／044＝139,300）で
全体の80%を占めていた。伸びる/沈むを分けているのは台本の丁寧さではなく**型**。
背景として、視聴者の**69.4%が55歳以上・91%が45歳以上**（TikTokインサイト実測）。

**優先して書く型（上から順）**
1. **年齢トリガー** — 「60歳」「64歳と65歳」「65歳を過ぎると」など、**年齢で自分が該当するか一瞬で分かる**型。
   n=4で中央値13,750、最大257,200。いまの視聴者層に最も刺さる。
2. **期限・タイミング** — 「誕生日の2日前までに」「退職の翌日から14日以内」。**過ぎたら取り返せない**線を引く。
3. **取られるお金を減らす** — 国保・住民税・社会保険料の減免/軽減。過去の最大バズ（1.1M・243,000・77,000）はここ。
4. **希少性・自分が該当するか** — 「受け取れる人はたった0.5%」（044＝139,300）。
5. **制度の抜け道** — 給付制限なし・受給期間の延長。中央値5,556。

**書かない型（実測で沈んでいる）**
- **手続き・ステップ解説**（「申請3ステップ」「記入項目」「必要書類」）— n=9で中央値2,841。最低は293。
- **給付金の総覧**（「知られざる給付金3選」）— 既視感が強い。1,470。
- **金額の大きさだけの訴求** — 「会社都合退職より**200万円**得する」は1,169再生。
  同じ内容を160万円に言い換えた版も712。**金額を大きくしても伸びない。**

**1行目に置く数字は「年齢・期限・日数」を選ぶ。金額ではない。**

| 効いた1行目（実測） | 再生 |
|---|---:|
| 65歳の誕生日の2日前までに退職しないと、失業手当と年金の両方はもらえません | 257,200 |
| 月収24万円でも、退職給付金の申請だけで430万円受け取れます | 139,300 |
| 60歳を迎えたら、申請しないと大きく損する給付金が3つあります | 16,800 |
| 会社を辞めた瞬間、住民税と国保は去年の収入のまま請求されます | 243,000 |

| 沈んだ1行目 | 再生 |
|---|---:|
| 失業手当は、手続きを間違えると、もらえなくなることがあります | 978 |
| 退職する前に知らないと、受け取れるはずの給付金を、何十万円分も逃します | 1,470 |
| 会社都合退職が得だと思っている人ほど、200万円以上損しています | 1,169 |

違いは「**誰の話か**」が1行目で確定するかどうか。沈んだ側はどれも対象者が絞られていない。

**同じ型を繰り返してよい。** 当たった角度は重複を理由に避けないこと。入口（対象年齢・期限・具体例）を
変えて何度でも出す。伸びた型を1回で捨てるのが、これまでの最大の取りこぼしだった。

### ② いいね・保存 誘導 — 本題直前に必ず入れる【固定文言】
```
この動画をもう二度と、あなたのおすすめには表示されませんので、忘れないよう、いいねと保存して。
```
- ※ 動画生成で **いいね・保存オーバーレイが自動で乗る**（「いいね」「保存」を含む文がトリガー）。
- **⚠️ 「忘れないよう」の後に必ず読点を打つ**（「忘れないよう、いいねと保存して」）。
  オーバーレイ行は**直前の1行と2列で1枚**に統合される仕様なので、読点で「忘れないよう」を独立させないと、
  1つ手前の「表示されませんので」まで巻き込んで3行が1枚になってしまう（＝「表示されませんので」と
  「忘れないよう」がテロップ分割されない）。正しくは「表示されませんので」で1枚、
  「忘れないよう／いいねと保存して」で1枚。

### ③ 本編 — 参考動画を完コピ
- 内容は参考動画のまま（完コピ）。
- **敬体は です/ます調に統一する**。参考動画がタメ口（ため口）なら、です/ます調に直す。
- 3選型なら本文中に ①②③ と番号を振る。「最後3つ目」の前振りで期待を持たせる。

### ③.5 中盤フォロー誘導 — 1つ目の項目が終わった直後に入れる【2026-07-30 追加】

**なぜ**: CTAは従来いちばん最後にしか無かったが、**フル視聴率は平均5.7%**。
＝フォロー誘導が届いていたのは**20人に1人だけ**だった。1つ目の項目が終わる地点（約30秒）なら
まだ4割前後が残っており、**到達者が6〜8倍**になる。フォロワー1万（Creator Rewards条件）への最大レバー。

```
退職のお金の話は
毎朝この時間に出しています
フォローしておくと見逃しません
```

- **位置**: 「1つ目」の項目の説明が終わり、「2つ目」に入る直前。
- **⚠️ この3行に「面談」「プロフィール」「リンク」「説明会」を絶対に入れない。**
  compose_video.py の `LINE_RE` がこの4語でLINE誘導オーバーレイの位置を決めており、
  該当行のテロップは削除される仕様。中盤で使うと中盤のテロップが消える。
  **「フォロー」はトリガー語ではないので安全**（この3行はフォローの話だけにする）。
- ⚠️ 「いいね」「保存」も入れない（②で発火済み。`LIKE_RE` は最初の1回で確定するため）。
- 「毎朝この時間に」は投稿時間（8:30）に合わせた表現。**フォローする"見返り"を必ず言う**のが要点で、
  「フォローしてください」だけでは効かない（見返りの無い依頼になる）。

### ④ CTA（フォロー＋LINE誘導）— 最後に必ず入れる【固定文言】
```
受給方法を詳しく知りたい人は
このアカウントをフォローして
無料の個別面談に参加してみてください
```
- 「受給方法を」の部分は動画テーマに合わせて可変（例:「申請方法を」）。
- **⚠️「退職のお金の話は／毎朝この時間に出しています」をここに書かない**（2026-07-30 社長指示）。
  この2行は ③.5 の中盤フォロー誘導で**1回だけ**言う。末尾で繰り返すとくどくなる。
- **語順は変えない**。「無料の個別面談に参加してみてください」が**最終行**であること。
  LINE誘導オーバーレイは `LINE_RE` に一致する**最後の行**に乗るため、
  この後ろに行を足すとオーバーレイが後続テロップに被る。
- **「無料の個別面談に参加してみてください」は LINE誘導オーバーレイが乗る文**。
  - 台本には文言を必ず入れる（オーバーレイの発火位置＝1フレームずらさない、の基準になるため）。
  - この文の**テロップは動画生成側で消す**（オーバーレイと重なるため。台本側では気にしない）。

## やってはいけない（CLAUDE.md 準拠）
- 「必ずもらえる」等の**断定・誇大表現を避け、事実ベース**にする。
- 公的制度（失業保険・給付金等）の説明は正確に。誤解を招く表現をしない。

## テロップの自動処理（台本の書き方で発火する）
動画生成側（compose_video.py）が、テロップ表示を自動で整える。台本はこれを前提に書く。
- **読点「、」の位置＝テロップの区切り**。区切りたい所に読点を打つ（例:「申請しないと損をする、給付金を…」で "する" の後で改行、「未払いのまま、退職した…」で "まま" の後で改行）。
- **「Nつ目、項目名。」と書くと `①項目名` の1枚テロップに自動統合**される（「Nつ目」は①〜⑤に置換、音声はそのまま「1つ目」と読む）。項目名は「Nつ目」の直後に置く。
- **いいね促し文**（「いいね」「保存」を含む行）は直前の行と1枚のテロップに自動統合（改行表示）される。
- **タイトル（フック）**は `make_video.py --title-lines 2` で冒頭2行を1枚のタイトルテロップに統合（1行目が赤）。行数はフックの行数に合わせて増減。

## 出力

> ⚠️ **このファイル中の「実例」「固定文言」のブロックは"完成後のテロップの見え方"であって、
> 台本の書き方ではない。** 台本は必ず**句読点のある普通の文章**で書き、**文の途中で改行しない**。
> テロップを割りたい位置には改行ではなく**読点「、」**を打つ。
>
> - ✗ 悪い（改行で割る）: `退職する人は全員` ⏎ `知っておくべき` ⏎ `退職給付金の制度があります`
> - ✓ 良い（読点で割る）: `退職する人は全員、知っておくべき、退職給付金の制度があります。`
>
> **なぜ**: `format_script.py` の `split_sentences` は**改行も文の区切りとして扱う**ため、
> 改行で書くと1行＝1文になり、**フックがバラけてタイトルカードが1行だけになる**
> （2026-08-04 本番_036 で発生）。`write_script.py` の `normalize_raw()` が保険として
> 自動修復するが、最初から文章で書くのが正しい。

- このルールで作った文章（句読点あり・普通の文章でよい）を `scripts/format_script.py` に渡す。
  → 句点=空行、読点=行区切り、30字改行、句読点除去 が自動でかかり、`make_video.py` に渡せる形になる。
  → 同時に CTA文・いいね文の有無もチェックされる。
