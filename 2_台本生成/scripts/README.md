# scripts — 台本工程の自動化

参考動画の**文字起こし**（`transcribe.py`）と、台本の**整形＋検査**（`format_script.py`）。

## venv（このフォルダの .venv 1つで両方動く）
```bash
cd 2_台本生成/scripts
python3.13 -m venv .venv
./.venv/bin/pip install yt-dlp faster-whisper fugashi unidic-lite Pillow
```
- `transcribe.py` … yt-dlp / faster-whisper を使う
- `format_script.py` … fugashi / Pillow を使う（改行判定を 3_動画生成 の telop_render.py と共有するため）
- ffmpeg も必須（導入済み）。

---

## transcribe.py — 参考動画 → 文字起こし（下書き）
```bash
./.venv/bin/python transcribe.py "https://vt.tiktok.com/XXXX/" -o ../文字起こし/ref_001.txt
```
- **入力**: TikTok等のURL（台本シートのG1に貼る参考動画）、またはローカルの音声/動画ファイル。
- **処理**: yt-dlp で音声取得 → faster-whisper（既定 `large-v3`）で日本語文字起こし。
- **出力**: 文字起こしテキスト。`-o` 省略で標準出力。
- 初回だけ Whisper モデルを `~/.cache` に自動DL（large-v3 は約3GB）。以降は使い回すので速い。

### ⚠ 文字起こしは「下書き」
Whisper は日本語の**数字・同音異義語を間違えることがある**（実例: 3選→3000、大損→保存、失業給付金→失業給付）。
そのまま完成台本にはしない。**この生テキストを [../プロンプト_台本生成.md](../プロンプト_台本生成.md) で AI に台本化させ、
その過程で誤りを直す**。台本化の中で固定文言（いいね保存／CTA）や です/ます統一も整える。

### オプション
| オプション | 意味 |
|---|---|
| `-o <path>` | 出力テキスト（省略時は標準出力） |
| `--model large-v3` | Whisperモデル（既定 large-v3。速さ優先なら medium / small だが精度は落ちる） |
| `--hint "..."` | 専門用語のヒント（initial_prompt）。既定は退職給付金ジャンルの用語。空文字で無効 |

## format_script.py — 台本（校正済み文章）→ make_video.py 用テキスト
```bash
./.venv/bin/python format_script.py 台本.txt -o ../../3_動画生成/音声/本番_014.txt
```
- **入力**: ふつうの文章（句読点あり）。文字起こしを AI 台本化したもの。
- **出力**: 1行1フレーズ／句読点なし／文末は空行。→ `make_video.py` にそのまま渡せる。
- `-o` を省くと**標準出力**へ（本文は stdout、サマリと警告は stderr）。

### 何をするか
| 元の文章 | 整形後 | 理由 |
|---|---|---|
| 句点「。」 | **空行**（文の区切り） | voicevox_tts が「大きい間＋文末SE」として読む |
| 読点「、」 | **行区切り**（改行） | 「小さい間」＝テロップ切替。元台本のリズムを再現 |
| 長い文（30字超） | 助詞・文節の切れ目で改行 | テロップ1枚に収める。数字・英字の途中では割らない |
| 、。「」（）等 | 除去 | 音声・テロップに不要（中黒「・」は残す） |

改行位置（助詞・文節の判定）は 3_動画生成 の `telop_render.py` と**同じロジックを共有**している
（台本の改行位置とテロップ内の折返し位置をズラさないため）。

### 同時に検査（lint）してくれること（stderr に警告）
- **CTA（LINE誘導）文が無い** … 末尾に「無料の個別面談に参加してみてください」等を
- **いいね・保存を促す文が無い** … 入れると いいね・保存オーバーレイが自動で入る
- **行が長すぎる**（`--max-len` 超）／**句読点・かぎ括弧の消し残り**
- 尺の推定も出す（過去実測 約498字＝1分）。

### オプション
| オプション | 意味 |
|---|---|
| `-o <path>` | 出力ファイル（省略時は標準出力） |
| `--max-len 30` | 1フレーズ（テロップ1枚）の最大文字数（既定30） |
| `--strict` | 警告があれば終了コード1で終わる（自動化で弾く用） |

## この工程の全体フロー
```
参考動画URL（1_リサーチ / 台本シートG1）
  │  ① transcribe.py … 文字起こし（下書き）
  ▼
文字起こしテキスト
  │  ② AI台本化 … プロンプト_台本生成.md で完コピ・固定文言・です/ます統一・誤り修正
  ▼
台本（校正済み文章）
  │  ③ format_script.py … make_video.py 用に整形＋検査
  ▼
台本テキスト → 3_動画生成/make_video.py で動画化
```
①③は自動、②は AI（Claude 等）が担当。台本の型は [../台本作成ルール.md](../台本作成ルール.md) を参照。
