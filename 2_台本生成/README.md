# 2_台本生成

## 役割
1_リサーチ で選定した参考動画をもとに、TikTok動画の台本（スクリプト）を作る工程。
講座メソッドの「ダウンロード → AI文字起こし → AI文章整理（リライト）」を担当する。
（この後の「AI音声」は 3_動画生成 で台本を音声化する）

## ★ 整形は自動（scripts/format_script.py）
校正済みの文章を渡せば、`make_video.py` にそのまま渡せる台本テキスト
（1行1フレーズ・句読点なし・文末空行）へ**自動整形＋検査**する。
```bash
cd 2_台本生成/scripts
../../3_動画生成/scripts/.venv/bin/python format_script.py 原稿.txt -o ../../3_動画生成/音声/本番_014.txt
```
CTA（LINE誘導）文の有無・行の長さ・句読点の残りも検査して警告する。詳細は [scripts/README.md](scripts/README.md)。

- **自動**: 30字改行・句読点除去・文末空行化・形式チェック（`format_script.py`）
- **AIが担当**: 台本の中身の創作（完コピ／リライト／フック・CTAの文言）

### 台本づくりの決まりごと（必読）
- **[台本作成ルール.md](台本作成ルール.md)** … 4パート構成（①タイトル ②いいね保存 ③本編 ④CTA）・
  固定文言・です/ます統一・尺の目安（約498字＝1分）など。過去の台本11本（Google Drive）から確定。
- **[プロンプト_台本生成.md](プロンプト_台本生成.md)** … 参考動画の文字起こし → 台本 を AI に作らせるプロンプト。
- 出てきた台本を `format_script.py` に通せば、そのまま `make_video.py` に渡せる。

## 基本方針: 伸びている動画は「完コピ（丸パクり）」推奨
- リサーチで「伸びている」と判明した参考動画は、**台本・構成・サムネ文言まで基本まるごとコピー**してよい。
- 割合の目安（講師の運用）: **約90%はパクり、10%だけ独自**。
- 「さすがにそのままはまずい」場合だけ、**1箇所だけ変える**（例: 雑学10選なら1項目だけ差し替える）。
- 構成・企画・切り口の模倣は、トップクリエイターも普通にやっている一般的な手法。
- 台本は、文字起こし → 校正（[プロンプト_文章整理.md](プロンプト_文章整理.md)）で、参考動画の内容を一言一句そのまま活かして作る（完コピ）。
- ※ 映像・画像などの素材の扱いは 3_動画生成（動画編集）で対応するため、ここでは扱わない

## 入力（前工程 1_リサーチ から受け取るもの）
- 参考動画リスト（動画URL・投稿日・テーマ・アフィリエイト導線への繋げ方メモ）

## 手順
### ①② ダウンロード＋文字起こし（自動：scripts/transcribe.py）
- 参考動画のURL（台本シートG1 / 1_リサーチ）を渡すと、音声取得→文字起こしまで一発。
  ```bash
  cd 2_台本生成/scripts
  ./.venv/bin/python transcribe.py "https://vt.tiktok.com/XXXX/" -o ../文字起こし/ref_001.txt
  ```
- 使用ツール: **yt-dlp（DL）＋ faster-whisper large-v3（文字起こし）**。ローカル完結・無料。
- ⚠ 文字起こしは**下書き**（Whisper は数字・同音異義語を間違える。例: 3選→3000、大損→保存）。
  次の③で AI が台本化するときに直す。詳細は [scripts/README.md](scripts/README.md)。

### ③ AI文章整理（台本化）
- 文字起こしテキストを **[プロンプト_文章整理.md](プロンプト_文章整理.md)** を使ってAIで校正・整形し、読みやすい台本テキストにする。
  - このプロンプトは「要約せず一言一句そのまま」で、誤字脱字・改行・てにをは・台詞の「」だけを整える校正用。
- **構成・企画・フックの型・順番は参考動画を完コピ**する（基本90%はそのまま踏襲）。
- 「そのままだとまずい」と感じた場合のみ、独自要素を1箇所だけ足す/差し替える（10%枠）。
- 整形後、フック（冒頭2秒）と **CTA（LINE誘導）** を整えて台本を完成させる。
  - 構成: フック → 本編（退職給付金の悩み共感/制度解説）→ CTA（LINE誘導）
- ルール（CLAUDE.md 準拠）:
  - 誇大・断定表現（「必ずもらえる」等）を避け、事実ベースにする
  - 最後に必ずLINE誘導CTAを入れる。締めの文言は「**無料の個別面談に参加してみてください**」でLINE公式アカウントへ誘導する

## 出力（次工程 3_動画生成 へ渡すもの）
- 台本ファイル（フック・本編・CTAのナレーション原稿＋テロップ文言＋シーン指示）
- キャプション/ハッシュタグ案

## 出力先の例
- `台本_YYYYMMDD_001.md` など（1動画=1ファイル）

## 進捗
- **①②ダウンロード＋文字起こしは自動化済み**（`scripts/transcribe.py`：yt-dlp＋faster-whisper）。
- **③の「AI音声用整形」は自動化済み**（`scripts/format_script.py`）。
- **AIが担当**: ③の台本化（文字起こし→台本。完コピ・固定文言・です/ます統一・誤り修正）。
  [プロンプト_台本生成.md](プロンプト_台本生成.md) と [台本作成ルール.md](台本作成ルール.md) を使う。
- これで **参考動画URL → 文字起こし → （AI台本化）→ 整形 → 3_動画生成** まで通る。
