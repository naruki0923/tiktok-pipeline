# もしも型 台本ルール（3D動画）

毎朝の自動生成（`scripts/write_moshimo.py`）がこのファイルを**丸ごと**プロンプトに載せる。
人が書く場所。機械（週次レビュー）は書き換えない。旧形式（散歩背景・完コピ）のルールは
`台本作成ルール.md` で、こちらとは別物。

参考: YouTube @Moshimo_Saigen の「もし◯◯したら？」の型（カウンター・時間経過・2段字幕）。
見た目と言い回しは丸写ししない。

## 型（この順番で1回ずつ）

1. **フック（hook）**: 「もし◯◯が△△だったら」の1文。2〜3行。
   - タイトル帯（画面上の固定タイトル）か1行目に、**年齢・期限・日数などの数字**を入れる
     （例:「もし退職後3か月、国保がゼロ円だったら？」）。金額の大きさは効かないので数字の主役にしない。
2. **もしもの世界（ideal）**: 制度がもっと良かったら、の想像。**時間を追って膨らませる**
   （1日目 → 1か月後 → 3か月後 → 半年後 → 1年後 のように4〜6区間）。
   - ここは自由に描いてよい（現実の制度の説明ではない）。画面に「※もしもの話です」が自動で出る。
   - 最後は「辞めることが怖くない国になりました」のような、世界が変わった結論で締める。
3. **巻き戻し**: 「でも現実は違います」— **自動で入る。書かない。**
4. **現実（real）**: 今の制度だと実際どうなるか。同じように時間を追う（1か月後 → 3か月後 → 半年…）。3〜5区間。
   - 手元のお金が減っていく・焦って合わない会社に入る、のような「取られる・追い込まれる」流れ。
5. **今の制度（system）**: 今の制度の中で取り戻す方法。3〜5区間。
   - 対象・条件・どこで・期限・「自分から届け出ないと使えない」を入れる。
6. **CTA**: 固定3行 — **自動で入る。書かない。**
   「申請方法を詳しく知りたい人は／このアカウントをフォローして／無料の個別面談に参加してみてください」

## 事実（いちばん大事）

- **現実・今の制度のパートに書く事実は、参考動画の文字起こしに出てくるものだけ**。
  制度名・条件・割合・期限・窓口を、文字起こしに無いのに足さない。分からない所は書かない。
- 文字起こしは誤変換を含む下書き。数字・同音異義語は文脈で直してよいが、内容は変えない。
- 断定・誇大表現（必ずもらえる・誰でも・100%）は使わない。「〜ことがあります」「〜人もいます」で。
- 使った事実は `facts` に「事実 ← 文字起こしのどの言い回しか」で書き出す（社長が投稿前に確かめる）。

## 書かないもの（社長指示 2026-11-16〜17）

- 「この動画をもう二度と…いいねと保存して」の誘導
- 中盤のフォロー誘導（「退職のお金の話は毎朝この時間に…」）
- 効果音（SE）の指定
- 65歳以上・65歳前後で退職する人向けの話（商材の対象は20〜64歳）。60歳の話は対象内
- 季節に依存する話（「◯月に辞めると」など、今日の月に当てはまらないもの）

## 尺

- **必ず1分を超える**。65秒前後を狙う。
- LLMが書く say の合計（巻き戻し・CTAは除く）を**空白抜きで350〜410字**。
  書いた後に VOICEVOX で長さを測り、外れていたら1回だけ直させる。

## カウンター（画面左上）

- 主人公は毎回同じ人（白髪まじりのスーツの男性）。**前提は固定**:
  貯金120万円・前の年の年収400万円・会社員を辞めた40代。
- `day` = 退職してから何日目。パートの中で戻らない。
- `money` = 手元のお金（万円）。**120から始まり、減るだけ**。もしもの世界はほとんど減らない
  （100〜120）、現実ははっきり減る。画面には「※数字はイメージです」が常に出る。

## 字幕

- `big`（大字幕）: その区間の要点を18字以内。言い切りの短い形（「収入ゼロでも、請求は届く」）。
- `sub`（小字幕）: 現実・今の制度で補足を22字以内。もしもの世界は自動で「※もしもの話です」。
- テロップでは「円」は消え「金」は◯になる。big/sub ではなるべく「金」「円」を使わない。

## 場面

自宅・公園・役所（看板は差し替え可。ハローワーク等）の3か所だけ。決まったショットの型から選ぶ。
この3か所で描けない話（会社の中・病院の中が要る話など）は ok=false にする。
