# 台本生成プロンプト（文字起こし → 台本）

参考動画の**文字起こし**を入力に、[台本作成ルール.md](台本作成ルール.md) に沿った台本を作らせるプロンプト。
AI（Claude 等）に投げて使う。出力はそのまま `scripts/format_script.py` に渡せる。

---

## プロンプト本文

```
あなたは退職給付金ジャンルのTikTok台本ライターです。
以下の【参考動画の文字起こし】をもとに、下記のルールで台本を作ってください。

# ルール
■ 基本
・参考動画の構成・内容は「完コピ」する（要約しない。順番・切り口はそのまま活かす）
・敬体は です/ます調に統一する（参考動画がタメ口なら です/ます調に直す）
・断定・誇大表現（「必ずもらえる」等）は使わず、事実ベースにする
・1行は短く（5〜20字、最大30字）。1行＝テロップ1枚のイメージ
・全体で約498字＝1分が目安

■ 構成（この4パートを上から順に必ず入れる）
① タイトル（フック）… 冒頭。「〜3選」等の列挙型。参考動画のタイトルをベースにする。
   最後に「特に最後の3つ目は」「知っておかないと大損する内容です」等で保存を促す。
② いいね・保存 誘導 … 本題直前に、次の固定文言を必ずそのまま入れる：
     この動画をもう二度と
     あなたのおすすめには表示されませんので
     忘れないよういいねと保存して
③ 本編 … 参考動画の内容を完コピ。3選型なら ①②③ と番号を振る。
④ CTA … 最後に、次の固定文言を必ずそのまま入れる（先頭は動画テーマに合わせて可変）：
     受給方法を詳しく知りたい人は
     このアカウントをフォローして
     無料の個別面談に参加してみてください

# 出力形式
・普通の文章（句読点あり）で、上から順に出力する
・パートの見出しや説明は付けず、台本本文だけを出力する

# 参考動画の文字起こし
<ここに文字起こしを貼る>
```

---

## 使い方
1. 参考動画（1_リサーチ で選定）を文字起こしする
2. 上のプロンプトの末尾に文字起こしを貼って AI に投げる
3. 出てきた台本を `scripts/format_script.py` に通す:
   ```bash
   cd 2_台本生成/scripts
   ../../3_動画生成/scripts/.venv/bin/python format_script.py 台本.txt -o ../../3_動画生成/音声/本番_014.txt
   ```
   → CTA文・いいね文の有無、行の長さ、句読点の残りが自動チェックされる
4. `make_video.py ../音声/本番_014.txt` で動画化
