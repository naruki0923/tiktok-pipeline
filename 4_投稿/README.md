# 4_投稿

## 役割
生成した動画をTikTokチャンネルへ投稿する工程。

## やること
- 投稿前チェック（内容・著作権・規約違反・誇大表現の有無）
- キャプション・ハッシュタグの設定
- TikTokへのアップロード（自動化手段は要検討: 公式API/サードパーティ/ブラウザ自動化）
- 投稿スケジュールの管理（時間帯・頻度）
- 投稿結果（投稿ID・URL・日時）の記録

## 入力（前工程から受け取るもの）
- 3_動画生成 の 動画ファイル + キャプション/ハッシュタグ

## 出力（次工程へ渡すもの）
- 投稿ログ（投稿ID・URL・投稿日時・使用キャプション）

## 出力先の例
- `投稿ログ.md` / `post_log.csv` など

## 注意
- 無人自動投稿のため、投稿前チェックを必ず通す設計にすること
- ログイン情報・API情報は `.env` 等に分離し、コミットしない
