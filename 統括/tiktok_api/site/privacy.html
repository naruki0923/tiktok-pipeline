Privacy Policy

Last updated: September 13, 2026

What this tool is

Video Stats Sync ("the tool") is a private application used only by its owner to read statistics of the owner's own TikTok videos. It is not made available to other users.

Data we access

When the owner signs in with TikTok, the tool requests the user.info.basic and video.list permissions. Through them it reads the owner's display name and avatar, and the list of the owner's videos with their title, link, creation time and public counts (views, likes, comments, shares).

How the data is used and stored

The data is downloaded to the owner's own computer and saved in local files. It is used solely to analyse which of the owner's videos perform well. The OAuth access token and refresh token are stored locally and are never shared.

Sharing

No data obtained from TikTok is sold, shared with, or transferred to any third party.

Retention and deletion

Data is kept on the owner's computer until the owner deletes it. The owner can revoke the tool's access at any time from TikTok's app settings ("Manage app permissions"), after which the tool can no longer fetch data.
