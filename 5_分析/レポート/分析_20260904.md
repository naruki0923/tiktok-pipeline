## 6. ★パイプラインが勝ち筋を自分で禁止している

`1_リサーチ/採用履歴.tsv` を集計した（全81件、不採用43件）。

**不採用理由が「国保・住民税・保険料の減免」だったもの＝14件。うち9件は8/17以降。**

| 日付 | 弾かれた参考動画の中核 |
|---|---|
| 08-17 | 所得激減による国保減免申請（保険料を半額に） |
| 08-17 | 非自発的失業者向け 国保料軽減（前年所得を3割とみなす） |
| 08-17 | 特定受給資格者/特定理由離職者の国保軽減・自治体独自減免 |
| 08-17 | 住民税の減免制度・国民健康保険料の減免制度 |
| 08-20 | 前年所得2/3以下での国保減免申請（年金天引きでも可） |
| 08-21 | 年金・保険の切替/免除申請ほか |
| 08-27 | 国保の法定軽減と自治体独自減免 |
| 09-02 | 税金・社会保険料の軽減制度ほか |
| 09-03 | 国保の高額請求／減額免除／非自発的失業者の軽減特例 |

**弾いた理由はすべて「2026-07-31採用済みの032と重複」。その032が243,000再生＝新体制2位の当たりである。**

`write_script.py` の重複判定は「同じ角度なら ok=false」としか書かれておらず、**その角度が当たったかどうかを見ていない**。結果:

- 当たった型 → 再び提案される → 「重複」で毎回落ちる → **二度と作れない**
- 外れた型（手続き・ステップ）→ 毎回違う制度なので重複しない → **9本作られる**

**これがパイプラインの構造的欠陥。** 前回レポートの「取られるお金を減らす型を月2〜3本に増やす」が1本も実行されなかったのは、社長がサボったからではなく、**システムがそれを禁止していたから**。

（同時に判定は一貫していない。067『退職給付金の受給率はたった0.5%』は、044『受け取れる人はたった0.5%です』（139,300）のほぼ同一ネタなのに通っている。結果的には正しい判断だが、ルールとしては働いていない。）
